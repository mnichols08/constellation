Floating nodes

Applies to nodes away from ring points, including disconnected nodes. Labels and lines follow. Choose Star field or turn snapping off to place nodes freely.

Positions & labels

Unlock positions to move nodes between ring points. Snapping is on by default: every move selects the nearest available point, swapping nodes when occupied. Each node has one corresponding ring point; hidden nodes hide and reserve their points.

Each node and its label stay attached. Unlock to drag either one and move the pair, or use arrow keys. Hold Shift for larger steps.

STYLE YOUR SKY

Visual styles

Individual nodes & colors
Individual nodes

Click a node in the chart or choose it below. A custom color applies in both light and dark mode.

Randomize gives every node in this view a different hue, including hidden nodes. Colored lines blend the colors of their two endpoints.

Hidden nodes also hide their connections. Enable Show labels in Visual styles to display individual labels.

Palettes & visual details

Adjust both palettes and the details below. Sky gradient sets the soft background glow, which fades to transparent edges. The image follows the viewer’s preference automatically; every change is included in your daily workflow.

CSS generated by these controls
Advanced CSS overrides

Selectors: .background, .star, .connections, .bridges, .repo-label, .credit, .generated-at. Use --sky-background, --sky-star, --sky-accent, --sky-line, and --sky-foreground for colors. Keep styles self-contained.

Save this as .github/workflows/constellation.yml in your README repository. Your settings and CSS are included—no extra config file needed.

Create this public repository first if it doesn’t exist ↗

  1. Commit the workflow. The button opens GitHub with your settings filled in. Commit to your repository’s default branch. If the file already exists, replace its contents with the workflow below.
  2. Run it once. Open Daily constellation ↗ Select Run workflow and wait for it to finish. Future runs happen daily.
