Need a token for local generation?

The browser preview stays token-free. A personal token can authenticate the local generator; the daily workflow already uses GitHub’s automatic token.

  1. Open GitHub’s fine-grained token form ↗.
  2. Choose a name, an expiration, your account as resource owner, and Public repositories. Leave extra permissions unset; public metadata is enough.
  3. Generate and copy the token. Create or edit .env in this project with GH_TOKEN=YOUR_TOKEN_HERE, replacing the placeholder.
  4. Run the command below with your username. Keep the token out of Git and this page.
node --env-file=.env src/cli.mjs --username YOUR_USERNAME --config constellation.config.json

GITHUB_TOKEN, GH_TOKEN, and gh_token are supported. GitHub’s token guide ↗
