# Guided setup

Start with **Continue with GitHub**, or **Explore a public account** using a GitHub user or organization. OAuth identifies your account automatically. Deployment owners must configure the [GitHub App and isolated exchange service](github-oauth.md); no personal token is needed in hosted onboarding.

1. **Choose what matters.** Welcome and profile identity lead into repository cards: description, language, topics, stars, recent activity, fork/archive state and discovered contributions. Recommended balances useful public signals. Recently active, Most starred, All and Contributed to provide quick selections. Search and select individual projects; up to 100 may be selected. Contribution discovery is bounded and incomplete; manually add public repositories when needed.
2. **What should your constellation reveal?** Choose projects, languages, topics, everything together, or let Constellation decide. These compile to existing node modes and connection bases. Optional language/topic refinement uses the same filters as Studio. Skip clears the topic filter; choosing no languages may leave no visible projects, with a recoverable explanation.
3. **Add a little life.** The default is no activity. Small visual symbols illustrate glow, commit asteroids, contribution orbit and pulsing recent activity. Requests only begin when generating an option that needs them. Asteroids load the existing bounded commit batch; other effects reuse the public activity cache. Missing optional data produces a quiet design with an explanation and Retry activity.
4. **Choose your universe.** Select a single constellation, identity rings or a connected galaxy. Profiles with at least six projects spanning three creation years also offer evolution and a universe through time. Retrospective views use creation dates and current metadata, never invented historical stars or topics. Choose feel and motion here.
5. **Preview.** Use this constellation, Generate another or Customize. Save a title, open fullscreen, or export SVG, PNG, interactive HTML or config JSON. Regeneration preserves your choices while varying the seed. Customize opens the six-tab advanced Studio. Edit answers and Back preserve choices.

Signed-in users with saved local constellations see **Continue your constellations**, with Open existing, Create another and Rerun onboarding. Reauthorization after a reload is required because tokens live only in memory. Anonymous users can also open Saved constellations. Named designs are local browser presets; export JSON for backup. Opening setup does not overwrite a previous draft; generating applies a new draft. Saved named designs remain intact.

Intent is a separate validated `constellation-intent-v1` browser record, never a renderer/config credential store. Metadata loads first, language details only after project selection, activity only on demand. Keyboard controls, visible focus, live loading status, narrow layouts and reduced motion remain supported. No drag operation is required.
