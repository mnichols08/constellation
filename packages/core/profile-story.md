# Profile Story output

Studio's **Export Profile Story (SVG)** always downloads a bounded Projects, Technical Shape, or Journey candidate: the explicitly selected story, or the current recommendation. This remains bounded while the main **Export SVG** reflects a custom manual view or Developer Atlas location. When a story candidate is on display, both downloads contain that same candidate scene. Actual project names are the proof points; language and topic labels only orient the reader when available. Candidate project selection is capped at twelve and deterministic, and unsupported themes or temporal stories are omitted rather than invented. For a compact recruiter-oriented README presentation, use the existing `readmePresentation: "recruiter"` option. Both outputs use the existing static SVG renderer and retain its accessible title and description and light/dark theme behavior.

This output describes visible project evidence. It must not be presented as a skill score, seniority assessment, recruiter ranking, or claim about professional growth.

Profile Story also offers compact 480px and wide 900px SVG exports. Both are composed from the same bounded candidate, with identical project identities and source evidence. Compact output emphasizes authored Featured and Supporting roles and reduces secondary label and relationship annotation density. It never removes selected projects. Story Clarity diagnostics are bounded estimates; browser checks cover actual rendered label and legend geometry.
