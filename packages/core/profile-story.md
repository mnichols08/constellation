# Profile Story output

Studio's **Export Profile Story (SVG)** downloads the exact bounded Projects, Technical Shape, or Journey scene currently selected or recommended. Actual project names are the proof points; language and topic labels only orient the reader when available. Project selection is capped and deterministic, and unsupported themes or temporal stories are omitted rather than invented. For a compact recruiter-oriented README presentation, use the existing `readmePresentation: "recruiter"` option. Both outputs use the existing static SVG renderer and retain its accessible title and description and light/dark theme behavior.

This output describes visible project evidence. It must not be presented as a skill score, seniority assessment, recruiter ranking, or claim about professional growth.
