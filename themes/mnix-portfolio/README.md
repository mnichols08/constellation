# Mnix portfolio theme

Saved before restoring Constellation's original navy, blue, and gold appearance.

- `palette.css`: reusable dark/light color variables for your portfolio. Load after your base CSS and use `var(--page)`, `var(--text)`, `var(--accent)`, etc.
- `preview.css` and `studio-layout.css`: exact snapshots of the complete Studio styles at the time of preservation. They include layout and component rules; load them in that order if you want the original Studio appearance.
- `constellation.json`: import this in Studio's Save tab to render the Mnix constellation with a transparent background for your portfolio. Select your own account, then download its SVG or generate an embed.

The built-in **Mnix (adaptive, transparent)** theme remains available in Studio. Existing Mnix configs and shares retain their palette.

Dark: charcoal `#111111`, olive borders `#555a38`, yellow accent/stars `#e3de13`. Light: ivory `#fafaf3`, olive accent `#595600`, gold stars `#8b8500`.
